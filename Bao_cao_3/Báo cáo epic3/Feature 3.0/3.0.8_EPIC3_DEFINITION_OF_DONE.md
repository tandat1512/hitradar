# ĐỊNH NGHĨA HOÀN THÀNH EPIC 3 (DEFINITION OF DONE)
**Tài liệu:** EPIC3_DEFINITION_OF_DONE.md  
**Feature:** 3.0.8 - Viết Definition of Done cho EPIC 3  
**Ngày cập nhật:** 2026-07-28  

EPIC 3 phải thỏa mãn các tiêu chí có thể ĐO LƯỜNG (Measurable) dưới đây để được coi là "DONE".

## 1. TIÊU CHÍ KỸ THUẬT BACKEND (FASTAPI)
- [ ] **B1 (Health Check):** HTTP GET `/health` phải trả về status 200 OK và chứa `"model_loaded": true` ngay sau khi start.
- [ ] **B2 (Model Loading):** Log server in ra dòng báo hiệu "Model loaded successfully" và nhận diện đúng SHA-256 (hoặc version 1.0.0) của file `.joblib`. Không có ImportError.
- [ ] **B3 (Performance - Predict):** HTTP POST `/predict` hoàn thành p95 response time < 100ms khi test với 100 requests tuần tự trên máy localhost.
- [ ] **B4 (Performance - Explain):** HTTP POST `/explain` sinh SHAP values trả về kết quả < 2000ms.
- [ ] **B5 (Documentation UI):** URL `http://127.0.0.1:8000/docs` (Swagger UI) tải thành công (HTTP 200), không lỗi CSS/JS, hiển thị đủ cấu trúc payload.
- [ ] **B6 (Error Code):** Gọi API thiếu trường `tempo` trả về HTTP 422 đúng chuẩn.

## 2. TIÊU CHÍ GIAO DIỆN FRONTEND (STREAMLIT)
- [ ] **F1 (Page Load):** Thời gian tải trang ban đầu (First Paint) của Streamlit trên localhost < 3 giây.
- [ ] **F2 (Navigation):** Click qua lại giữa 6 tab menu ở sidebar không ném ra exception nào trên giao diện.
- [ ] **F3 (Validation):** Nhập giá trị `danceability` = 1.5 vào `st.number_input` (không phải slider), bấm "Dự đoán". UI phải hiển thị `st.error()` với message rõ ràng, không gọi API. Tương tự, gửi trực tiếp POST request với `danceability = 1.5` qua cURL hoặc Postman — Backend phải trả về HTTP 422 với detail chỉ rõ field và giá trị lỗi.
- [ ] **F4 (Integration):** Khi Fast API đang tắt, bấm "Dự đoán" phải hiện ra Toast Error hoặc Banner báo lỗi không kết nối được, không hiện thông báo crash code Python.
- [ ] **F5 (Render Chart):** Trả về được kết quả từ `/explain` và vẽ thành công ít nhất 1 SHAP Waterfall/Bar chart trên màn hình bằng thư viện phù hợp.

## 3. TIÊU CHÍ VẬN HÀNH & BÀN GIAO (DELIVERY)
- [ ] **I1 (Setup):** Gõ `pip install -r requirements-runtime.txt` và `requirements-explainability.txt` trên môi trường Python 3.9/3.10 hoàn thành với Exit Code 0 (không conflict).
- [ ] **I2 (Scripts):** Script `run_all.bat` (hoặc sh) bật thành công cả terminal uvicorn và terminal streamlit mà không tự exit.
- [ ] **D1 (Report):** File Word (.docx) Báo cáo tổng hợp dự án hoàn tất đủ chương EPIC 1, 2, 3 và có độ dài hợp lý (>30 trang). Định dạng .docx (không phải PDF) để thuận tiện chỉnh sửa và đánh giá.
- [ ] **D2 (Presentation):** Slide có ít nhất 15 trang, bao gồm mục tiêu, kiến trúc, SHAP limitations và màn hình demo.
- [ ] **D3 (Backup):** Đã thu âm/quay hình (mp4) ít nhất 3 kịch bản Demo chính (Happy path, what-if, limitations) nằm trong folder `demo_backups`.
