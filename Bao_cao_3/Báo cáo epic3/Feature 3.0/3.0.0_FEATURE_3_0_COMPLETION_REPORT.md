## 2. NHỮNG THAY ĐỔI ĐÃ THỰC HIỆN TRONG HOTFIX
1. **INPUT_ARTIFACTS.md:** Đã thêm thông tin Repository path, người tạo/người nhận (Producer/Consumer), mức độ Require, Version và Validation rules cụ thể. Bổ sung template checksum.
2. **OUTPUT_DELIVERABLES.md:** Đã cấu trúc lại thành bảng danh sách các file/folder cụ thể sẽ xuất hiện trong codebase sau khi hoàn thành EPIC 3 (thay vì đoạn văn mô tả chung).
3. **API_CONTRACT.md:** Cụ thể hóa data type, required, nullable, min/max range cho cả 18 features payload. Chuẩn hóa format lỗi HTTP 400, 404, 422, 500 và thêm JSON example.
4. **UI_UX_CONTRACT.md:** Đã thêm sơ đồ luồng dữ liệu (Sequence diagram) và liệt kê 6 trạng thái xử lý chi tiết (Empty, Loading, Lỗi Validation, Lỗi API, Lỗi Model, Success).
5. **FRONTEND_DATA_CONTRACT.md:** Thêm API Version, Contract Version 1.0.0. Thêm giá trị default cho Form UI và payload gửi mẫu toàn vẹn.
6. **DEMO_SCENARIOS.md:** Bổ sung Kịch bản Lỗi (Error Handling Paths) gồm thiếu feature, server sập, model lỗi và timeout để test độ "chống vỡ" của ứng dụng.
7. **EPIC3_DEFINITION_OF_DONE.md:** Các điều kiện đóng dự án đã được chuyển thành hành động có thể đo đếm bằng định lượng (VD: response time < 100ms, HTTP code 200, lệnh pip trả về exit code 0).
