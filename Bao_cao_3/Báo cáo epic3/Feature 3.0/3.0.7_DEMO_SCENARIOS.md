## LUỒNG THÀNH CÔNG (HAPPY PATHS)

### KỊCH BẢN 1: DỰ ĐOÁN BÀI HÁT TƯƠNG LAI
1. **Hành động:** Truy cập trang **Predict**, nhập `release_year` = 2023, kéo `danceability` = 0.8, `explicit` = 1. Nhấn **Dự đoán**.
2. **Kỳ vọng:** Trả kết quả <100ms, hiển thị thanh điểm số và biểu đồ SHAP chỉ rõ đóng góp của năm phát hành.

### KỊCH BẢN 2: SO SÁNH WHAT-IF (A/B TESTING)
1. **Hành động:** Truy cập **What-If**, để Cột A là Nhạc Studio cũ, Cột B là Nhạc Club mới. Nhấn **So sánh**.
2. **Kỳ vọng:** Trả về delta điểm chênh lệch và hiển thị mũi tên màu xanh/đỏ hợp lý.

### KỊCH BẢN 3: HIỂN THỊ LIMITATIONS
1. **Hành động:** Mở tab **Limitations**.
2. **Kỳ vọng:** Trình bày R2 = 0.069, giải thích rằng model có tính tham khảo, không khẳng định 100%.

## LUỒNG XỬ LÝ LỖI (ERROR HANDLING PATHS)

### KỊCH BẐNH 4: LỖI VALIDATION / THIẾU FEATURE (Backend — API trực tiếp)
1. **Ngữ cảnh:** Test tầng API bằng công cụ bên thứ ba.
2. **Hành động:** Gửi POST `/predict` qua cURL hoặc Swagger với payload thiếu trường `tempo`:
   ```bash
   curl -X POST http://localhost:8000/predict \
     -H "Content-Type: application/json" \
     -d '{"duration_min": 3.5, "explicit": true, ... }'  # thiếu tempo
   ```
3. **Kỳ vọng:** Backend trả về `HTTP 422 Unprocessable Entity` kèm body:
   ```json
   {"error": true, "code": 422, "message": "Validation error",
    "detail": {"field": "tempo", "reason": "Missing required field"}}
   ```

### KỊCH BẢN 4b: LỖI VALIDATION (Frontend — Streamlit UI)
1. **Ngữ cảnh:** Test tầng giao diện người dùng cuối.
2. **Hành động:** Trên trang **Predict**, xóa giá trị `release_year` (để trống), bấm **Dự đoán**.
3. **Kỳ vọng:** Streamlit hiển thị `st.error("Giá trị không hợp lệ: release_year là bắt buộc.")` — UI không sập, vẫn hiển thị form. Backend không nhận được request vì Streamlit validate trước khi gọi API.

### KỊCH BẢN 5: API KHÔNG PHẢN HỒI (CONNECTION REFUSED)
1. **Ngữ cảnh:** Môi trường production gặp sự cố, server FastAPI bị sập.
2. **Hành động:** Tắt cửa sổ dòng lệnh đang chạy FastAPI. Bấm **Dự đoán** trên giao diện Streamlit.
3. **Kỳ vọng:** Streamlit hiện thông báo đỏ `st.error("Lỗi: Không thể kết nối tới Backend. FastAPI có đang chạy không?")` sau khi kết nối thất bại, UI không crash.

### KỊCH BẢN 6: MODEL LOAD THẤT BẠI (INTERNAL SERVER ERROR)
1. **Ngữ cảnh:** File `.joblib` bị xóa, đổi tên, hoặc khác phiên bản thư viện.
2. **Hành động:** Đổi tên file `full_inference_pipeline.joblib` thành tên khác, rồi gọi API.
3. **Kỳ vọng:** Backend khởi động báo lỗi rõ ràng, hoặc API trả về `HTTP 500 / 503`. Streamlit báo `st.error("Lỗi từ hệ thống Backend: Không tìm thấy model inference.")`

### KỊCH BẢN 7: PREDICTION TIMEOUT
1. **Ngữ cảnh:** Backend quá tải hoặc SHAP tính toán quá chậm trên máy yếu.
2. **Hành động:** Thêm `time.sleep(10)` vào API. Bấm nút Dự đoán.
3. **Kỳ vọng:** Streamlit chờ hết 5 giây (timeout configured) và báo `st.warning("Request Timeout: Backend phản hồi quá chậm.")`
