## 2. VÍ DỤ PAYLOAD ĐẦY ĐỦ GỬI ĐI TỪ STREAMLIT
Khi user nhấn nút "Dự đoán", Streamlit client (hoặc hàm requests.post) sẽ tạo chính xác object JSON sau để gửi đi. Mọi sai lệch về tên biến hoặc kiểu dữ liệu sẽ bị FastAPI chặn (HTTP 422).

```json
{
  "release_year": 2020,
  "release_month": 5,
  "decade": 2020,
  "release_precision": "day",
  "duration_min": 3.5,
  "explicit": 0,
  "danceability": 0.7,
  "energy": 0.6,
  "key": 5,
  "loudness": -6.5,
  "mode": 1,
  "speechiness": 0.05,
  "acousticness": 0.2,
  "instrumentalness": 0.0,
  "liveness": 0.1,
  "valence": 0.4,
  "tempo": 120.0,
  "time_signature": 4
}
```

## 3. QUY TẮC CẤM VÀ AUTO-COMPUTE
- **Không gửi trường `target_popularity`** và **`track_id`**.
- Frontend phải tự động gán giá trị `decade` bằng biểu thức toán học dựa trên `release_year` (Vd: `release_year = 2024 -> decade = 2020`), không để user nhập trường `decade`.
- Trước khi gọi API, UI chạy qua bộ kiểm tra nội bộ (Pydantic model ở client hoặc st.slider min/max enforcement) để bảo vệ server.
