## 1. Request Validation (Cấu trúc Payload 18 Features)
Được dùng cho `/predict` và `/explain`.
Mọi request bị bắt lỗi ở Schema Validation sẽ trả về `HTTP 422 Unprocessable Entity`.

| Field | DataType | Required | Nullable | Min | Max | Enum | Ghi chú |

| `decade` | integer | YES | NO | 1900 | 2020 | - | Chỉ cho phép bội số của 10 |
| `release_precision`| string | YES | NO | - | - | `"day","month","year"` | - |
| `duration_min` | float | YES | NO | 0.0 | 100.0| - | - |

| `danceability` | float | YES | NO | 0.0 | 1.0 | - | - |
| `energy` | float | YES | NO | 0.0 | 1.0 | - | - |

## 2. Chuẩn hóa Error Responses
| HTTP Status | Trường hợp | Response Format |
|-------------|------------|-----------------|
| **400 Bad Request** | Logic lỗi (vd: model chưa load, business rules vi phạm). | `{"detail": "Error message"}` |
| **404 Not Found** | URL endpoint không tồn tại. | `{"detail": "Not found"}` |
| **422 Unprocessable Entity** | Thiếu trường, sai kiểu dữ liệu, vượt min/max. | FastAPI Default `{"detail": [{"loc": [...], "msg": "...", "type": "..."}]}` |
| **500 Internal Server Error** | Model crash, SHAP fail, exception trong hệ thống. | `{"detail": "Internal server error: [reason]"}` |

## 3. Endpoints

### 3.1 `POST /predict`
**Request Example:**
```json
{
  "release_year": 2020, "release_month": 5, "decade": 2020,
  "release_precision": "day", "duration_min": 3.5, "explicit": 0,
  "danceability": 0.7, "energy": 0.6, "key": 5, "loudness": -6.5,
  "mode": 1, "speechiness": 0.05, "acousticness": 0.2,
  "instrumentalness": 0.0, "liveness": 0.1, "valence": 0.4,
  "tempo": 120.0, "time_signature": 4
}
```
**Success Response (200 OK):**
```json
{
  "prediction_raw": 65.43,
  "prediction_clipped": 65.43,
  "prediction_display": "65",
  "status": "success"
}
```
**Error Response Example (422 Unprocessable Entity):**
```json
{
  "detail": [
    {
      "loc": ["body", "danceability"],
      "msg": "Input should be less than or equal to 1.0",
      "type": "less_than_equal"
    }
  ]
}
```

### 3.2 `POST /explain`
**Request:** Giống hệt `/predict`.
**Success Response (200 OK):**
```json
{
  "base_value": 29.56,
  "prediction": 65.43,
  "contributions": [
    {"feature": "release_year", "value": 2020, "contribution": 15.2, "type": "positive"},
    {"feature": "acousticness", "value": 0.2, "contribution": -2.3, "type": "negative"}
  ]
}
```

### 3.3 `POST /what-if`
**Request Schema:**
```json
{
  "scenario_a": { /* 18 features dict */ },
  "scenario_b": { /* 18 features dict */ }
}
```
**Success Response (200 OK):**
```json
{
  "scenario_a_result": 65.43,
  "scenario_b_result": 72.10,
  "delta": 6.67,
  "features_changed": ["danceability", "explicit"]
}
```

### 3.4 `GET /health` & `GET /model-info`
- Xem định nghĩa ở file báo cáo trước đó. Trả về metadata và trạng thái hệ thống.
