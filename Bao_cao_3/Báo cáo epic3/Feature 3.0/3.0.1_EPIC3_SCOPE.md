## 1. MỤC TIÊU (OBJECTIVES)
- Chuyển đổi (productize) các artifacts từ mô hình máy học tốt nhất của EPIC 2 (XGBoost `EXP24-XGB-FINAL-001`) thành một hệ thống phần mềm hoàn chỉnh.
- Xây dựng **FastAPI Backend** cung cấp các dịch vụ suy luận (Inference), giải thích (SHAP Explainability) và so sánh kịch bản (What-if).
- Xây dựng **Streamlit Frontend** để người dùng cuối (không chuyên kỹ thuật) có thể tương tác với mô hình, xem xu hướng 100 năm của Spotify và đánh giá chất lượng dự đoán.
- Hoàn thiện toàn bộ hệ thống tài liệu hướng dẫn, báo cáo kỹ thuật, slide bảo vệ để chuẩn bị cho hội đồng đánh giá.

## 2. PHẠM VI (IN SCOPE)
EPIC 3 tập trung 100% vào đóng gói và trình diễn. Phạm vi công việc bao gồm:
- **Backend**: Xây dựng 4+ endpoints RESTful API (/predict, /explain, /what-if, /model-info). Setup logging, error handling và CORS.
- **Frontend**: Tạo multi-page Streamlit app với 6 tabs chính (Overview, Predict, What-If, Trends, Model Info, Limitations).
- **Integration**: Giao tiếp ổn định giữa UI (Port 8501) và API (Port 8000). Benchmark latency < 100ms.
- **Quality Assurance**: End-to-end testing, error handling cho các trường hợp input sai format/thiếu dữ liệu, test trên máy sạch (clean environment).
- **Documentation**: README, How-to-run, Báo cáo tổng hợp dự án, Phụ lục kỹ thuật, User Manual, API Docs.
- **Defense Preparation**: Slide trình bày, kịch bản demo (demo script), Q&A cho hội đồng và chuẩn bị kịch bản fallback/offline demo.

## 3. NGOÀI PHẠM VI (OUT OF SCOPE)
Để đảm bảo chất lượng, các hạng mục sau bị NGHIÊM CẤM thực hiện trong EPIC 3:
- Không huấn luyện (train) lại bất kỳ mô hình Machine Learning nào.
- Không điều chỉnh siêu tham số (hyperparameter tuning).
- Không thêm hoặc bớt features khỏi tập 18 baseline inputs đã chốt.
- Không thay đổi pre-processing logic (như imputation, scaling) hoặc fit lại các bộ encoders.
- Không clean lại dữ liệu thô (raw data).
- Không xây dựng cơ sở dữ liệu mới cho hệ thống (toàn bộ dữ liệu phục vụ UI như trends sẽ đọc trực tiếp từ static files hoặc cache từ API).

**Giả định:**
- Gói `full_inference_pipeline.joblib` hoạt động đúng như tài liệu chứng minh của EPIC 2, không cần can thiệp logic bên trong.
- Máy của giáo viên/hội đồng khi chạy thử hỗ trợ Python 3.9+ và cài đặt được các thư viện yêu cầu.

**Rủi ro và Chiến lược giảm thiểu:**
1. **Rủi ro API/UI kết nối thất bại (CORS, Port conflict)**: Setup middleware chuẩn ngay từ đầu. Hướng dẫn đổi port dễ dàng qua biến môi trường.
2. **Rủi ro Latency khi sinh biểu đồ SHAP**: SHAP waterfall plot có thể tốn thời gian sinh ở backend hoặc UI. Sẽ sinh sẵn (pre-compute) nếu quá lâu, hoặc tối ưu payload serialize.
3. **Rủi ro sập app khi demo (Demo Effect)**: Chụp lại screenshots mọi luồng chuẩn bị slide dự phòng; có khả năng quay video backup.
4. **Rủi ro sai lệch định dạng đầu vào**: Thiết lập Pydantic models chặt chẽ ở FastAPI, Streamlit UI có ràng buộc số học (slider/selectbox) để chặn input rác từ đầu.
