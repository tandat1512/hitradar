# Data import implementation

The canonical raw-data ingestion path is `9.SCRIPTS/import_raw_data.py`. The
former numbered SQL files in this directory were empty placeholders and have
been removed to avoid implying that a second SQL ingestion pipeline exists.

Database schemas and tables are created by the scripts in
`2.DATABASE_SQL/2.1.tao_bang/`. Import validation evidence is documented in
`6.TAI_LIEU/6.1.bao_cao/RAW_IMPORT_VALIDATION_REPORT.md` and
`6.TAI_LIEU/6.1.bao_cao/IMPORT_LOG.md`.
